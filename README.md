# BAMAKAN

**B**order-**A**pproximation **M**onotone **A**dditive **K**appa-**A**daptive **N**etwork: an interpretable classifier
that learns, for each criterion, a weight and ordered border levels (reference levels) from labelled data.

- **Readable.** Every prediction is a sum of signed criterion contributions measured against borders that are reported
  in the criteria's original units. A fitted model converts into an integer if-then point score.
- **Monotone by construction** for binary and ordinal outcomes, with preference directions fixed before fitting.
- **Inductive and stable.** Normalisation bounds and borders are estimated on the training data and frozen, so
  scoring new cases never changes the scores of existing ones.
- **Compact.** A fitted model is a few kilobytes and stores no training records.

This repository contains the implementation and everything needed to reproduce the results of the paper
*"BAMAKAN: A Learnable Border-Approximation Classifier with Monotone, Criterion-Level Explanations"*
(S. M. Hosseini Bamakan, Masaryk University; manuscript under review).

## Quick start

```bash
pip install -r requirements.txt
```

```python
from bamakan import BAMAKANClassifier
from experiments.benchmark import BAMAKAN_CONFIG

clf = BAMAKANClassifier(task="binary", **BAMAKAN_CONFIG).fit(X_train, y_train)  # "binary" | "ordinal" | "nominal"
clf.predict_proba(X_test)
clf.explain(X_test[:1])                    # signed contribution of each criterion
clf.borders_in_original_units(names)       # learned border levels in original units
clf.feature_importances(X_train)           # mean |centred contribution| on the logit scale

card = clf.scorecard(names, X=X_train, y=y_train)   # integer if-then point score (binary and ordinal tasks)
clf.predict_proba_scorecard(X_test, card)
```

For datasets with fewer than about 2,000 cases, a simpler configuration (`n_borders=1`, or a fixed κ) is as accurate
and more compact; the default configuration pays off on larger datasets.

## Repository layout

| Path | Content |
|---|---|
| `bamakan/` | `BAMAKANClassifier` (`core.py`), GMLVQ baseline, split-conformal utilities |
| `tests/` | unit tests: power-mean gradients, border ordering, monotonicity, reflection invariance, border round trip |
| `experiments/` | data loaders, model configurations and experiment runners |
| `analysis/` | statistics, efficiency measurements, clinical analyses, tables and figures |
| `data/external/` | datasets not available through Python packages (see `data/README.md`) |
| `results/` | per-fold results (JSON) of every experiment |
| `tables/`, `figures/` | generated by the analysis scripts |

## Reproducing the results

```bash
pytest tests

# Synthetic experiments (recovery, stability, regimes; correlation, interaction and covariate shift)
python experiments/synthetic.py
python experiments/synthetic_ext.py

# Repeated stratified CV (2 x 5 folds) of all models on 31 datasets; resumes from results/cv/parts
python experiments/run_cv.py <dataset> [...]          # dataset names: see experiments/ablation.py (DATASETS_ALL)
python experiments/run_tabpfn.py                      # TabPFN (GPU recommended; Colab notebook in experiments/)

# Ablations and further analyses
python experiments/ablation.py [n_workers]
python analysis/partial_directions.py                 # conditional vs marginal directions
python analysis/kappa.py                              # what the learned kappa does and does not describe
python analysis/efficiency.py                         # controlled size / time / memory measurements
python analysis/clinical.py                           # CIs, recall, calibration, conformal, point scores, stability

# Tables and figures of the paper
python analysis/make_tables.py
python analysis/make_figures.py
```

All result files used in the paper are included in `results/`, so the analysis scripts run without re-training.
EBM variants were evaluated on the first five folds only because of their training time; TabPFN was run on an
NVIDIA T4 GPU (TabPFN-3.5 weights).
